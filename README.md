# Kimun-y-su-Aventura-Agroecol-gica
# 🌻 Granja Viva  Simulador educativo sobre agroecología, reciclaje y circuitos productivos para chicos de 6 a 12 años. Inspirado en la granja agroecológica de Juana Koslay, San Luis. Cuidá animales, cultivá, reciclá y vendé lo que producís. Funciona en el navegador, sin instalación.
